# ポケモン まなびのぼうけん

iPadで使える、小学1年生向けの算数・国語ドリルです。12問クリアするごとに、PokeAPIの全国図鑑1,025種類に加え、メガシンカ97種・キョダイマックス34種の姿も捕まえられます（図鑑の「すがた」で絞り込み・「メガ」「キョダイ」で検索できます）。未捕獲のポケモンを優先し、余りの問題数は次回へ引き継ぎます。

今日のドリルは、さんすう→こくごを終えると記録を保存して、そのまま次のラウンド（新しい問題のさんすう）が始まります。やめたいときは「あとで つづける」でいつでも中断でき、同じ画面から再開できます。12問のクエストは1日に何回でも挑戦できます。同じクエストの再挑戦・別クエストへの移動ができ、捕獲数に上限はありません。その日5匹捕まえたあとの「またあした」は声かけで、その後も続けられます。

算数は足し算・引き算、1〜3の段の掛け算、文章題、時計。国語はひらがな・カタカナ、1年生の漢字、ことば、短い文章の読み取りです。

問題は日付ごとのシードから毎回組み立てるため、同じ日は同じ内容、別の日は別の内容になります。1回のドリルの中で同じ問題は出しません。出題の形式と素材は`dist/drills.js`にまとまっています。

- 算数: たし算・ひき算（穴埋め□、3つの数、数の並び、10になる数、わけっこ、となりの数、10と□、絵を数える、何番目、大小比べ）、掛け算（図つき・穴埋め・文章題・しき選び）、文章題13種類（おかね・ならんでいる人数・「より多い／少ない」を含む）、時計（読み・1〜3時間前後・30分後・長い針の位置）。出題の順番は毎回入れ替えます。
- 国語: ひらがな（絵・しりとり・五十音の順・濁点と半濁点・文字数・穴埋め・ならべかえ）、カタカナ（変換・外来語・ポケモン名）、かんじ（1年生の漢字約80字の読み書き・絵あて・漢数字の計算）、ことば（反対ことば・なかま外れ・なかま分け・数え方・音のことば・曜日・季節・助詞「は／を／へ」）、ぶんを よもう（5W1Hの読み取り・ならべかえ・出来事の順番・理由）。

## GitHub Pagesで公開する

1. このソースをGitHubリポジトリの`main`ブランチに置きます。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. **Actions → Publish learning app to GitHub Pages → Run workflow** を実行します。以降、`main`へのpushで自動公開されます。
4. デプロイが成功すると、Actionsの`github-pages`環境に公開URLが表示されます。

無料プランで利用する場合は、通常は公開リポジトリを使います。GitHub Pagesに公開するのは`dist`の静的ファイルだけです。利用者の学習記録をGitHubへ送ることはありません。

## 開発・確認

Node.js 22で、外部パッケージのインストールなしに実行できます。

```sh
npm run check
npm test
npm run build
```

`dist/index.html`は学習機能と日本語図鑑を組み込んだHTMLです。静的HTTPサーバーで`dist`を配信して確認できます。PokeAPIの詳細情報とポケモン画像の取得にはインターネット接続が必要です。

GitHub PagesのプロジェクトURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）でも、相対パスで画像・マニフェストを読み込めます。ビルドに特定のマシンの`/workspace`ディレクトリは必要ありません。

## メガシンカ・キョダイマックスのデータ

`dist/forms.js`はPokeAPIから生成したスナップショットです（日本語名は「メガ＋名前」「キョダイ＋名前」の規則で付けています）。新しいフォームが追加されたら `node scripts/build-forms.mjs` で再生成できます（要ネットワーク）。

## 記録の保存

記録は端末のブラウザのlocalStorageに自動保存します。同じ端末・同じブラウザ・同じ配信元で使うと続きから再開できます。別端末との同期はありません。プライベートブラウズの終了やサイトデータの削除で失われることがあります。

「おうちのかたへ」→「記録をファイルに保存」でバックアップ（JSON）を書き出せ、「ファイルから読み込む」で復元できます。URLや端末を変える前に保存しておくと安心です。

配信元がChatGPT SitesからGitHub Pagesに変わると、ブラウザの保存領域も変わります。以前の記録は以前のURLに残り、新しいURLには自動移行されません。バックアップを経由して移せます。

個人用・非公式の学習アプリです。画像・図鑑データはPokeAPIを使用しています。ポケモンの名称・画像は各権利者に帰属します。
